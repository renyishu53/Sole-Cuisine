- **路由空白真因（二刷）**：控制台 `[Vue warn]: Component inside <Transition> renders non-element root node that cannot be animated` 指向 `CalendarView`。`AppShell` 用 `<Transition mode="out-in">` 包裹 `<RouterView>`，Vue 要求子组件单根；`CalendarView.vue` 与 `MembersView.vue` 的 `<template>` 是「`<AsyncState>` + `<Teleport to="body">」双根，导致 out-in 离场钩子不触发、新组件挂不上 → 空白需手动刷新。修复：两组件模板外层各加单根 `<div class="page-view" style="display: contents">`（`display:contents` 不生成布局盒子，不影响排版）。
- 验证：`npm run build` 通过（20.79s）。
- 注：控制台 `chrome-extension://` 与 `401` 均非路由问题（前者是浏览器插件，后者是刷新后 session 丢失被重定向到 /login）。
