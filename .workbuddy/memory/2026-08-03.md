# 2026-08-03 工作日志

## CasaMind 项目工作流架构分析

- 项目：CasaMind — Graph RAG + 多智能体家庭事务规划平台
- 工作流框架：LangGraph (`langgraph-0.6.11`)，单个 `StateGraph` DAG，核心在 `backend/app/ai/workflow.py`
- 11 个节点：intent → 双路检索并行 (Neo4j graph_retriever + Chroma vector_retriever) → coordinator → 4 个领域专家并行 (meal/shopping/task/budget) → planner → verifier → final_planner
- **无子智能体**：无 subgraph、无嵌套图、无 agent 间委托，单层扁平 DAG（全代码库仅一处 `compile()`）
- **复杂度评估**：实际真正调 LLM 的只有 planner 节点；4 个"专家 Agent"是硬编码建议字符串（`_specialist_result` 返回固定文本），intent 也是静态字典 — 多节点结构主要为前端 Agent Trace 可视化服务，属于演示型架构而非真实多智能体
- LLM 集成：langchain-openai + `with_structured_output`，Demo/真实双模式，失败可降级
- 状态设计：`specialist_outputs` 和 `trace` 用 `operator.add` reducer 聚合并行结果
- 已用 SVG 流程图向用户展示完整工作流设计流程（入口→intent→双路检索→coordinator→四专家→planner→verifier→final_planner→响应）
