## CasaMind 项目全量源码分析

通读仓库全部关键文件（README、HomePilot_PRD.md、docker-compose.yml、backend 18 个 py、frontend 23 个源文件、docs、.env），产出《CasaMind 项目分析报告.md》于项目根目录。核心结论：

- 项目 = CasaMind（PRD 原名 HomePilot），Graph RAG + 多智能体 AI 家庭事务规划平台

## 修复前端路由切换页面空白 bug

症状：客户端切换路由后视图空白（DOM 只剩 `<!---->`），刷新浏览器后正常。用 playwright-core + 系统 Chrome（装在 managed node workspace，脚本在 temp 目录）复现确诊。

根因：AppShell 的 `<Transition name="page" mode="out-in">` 包裹 RouterView，out-in 要求旧视图 afterLeave 后才挂载新视图；数据视图根组件 AsyncState 加载完成后渲染 `<slot v-else/>`（Fragment 根），Vue 无法挂过渡钩子 → afterLeave 永不触发 → 新视图永不挂载。刷新走初始渲染路径所以正常。

修复（已验证 20/20 导航 PASS、0 Vue 警告、vue-tsc 通过）：
1. `frontend/src/components/AsyncState.vue`：模板外套 `<div class="async-state">` 单一元素根
2. `frontend/src/components/AppShell.vue`：Transition 内 component 加 `:key="route.path"`

顺手沉淀用户级技能 `~/.workbuddy/skills/vue-transition-blank-page/SKILL.md`。另确认认证存储设计：用户主数据→PostgreSQL，会话/refresh token→Redis，Neo4j 仅存偏好检索副本，Chroma 不存用户信息。
