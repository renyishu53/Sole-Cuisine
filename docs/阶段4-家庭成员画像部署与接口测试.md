在 Yaak 创建 Environment，配置：

后续 URL 使用 `{{base_url}}`。需要认证的请求增加 Header：

```text
Authorization: Bearer {{access_token}}
Content-Type: application/json
```

## 7. Yaak 接口测试顺序

### 7.1 登录并获取 Token

```http
POST {{base_url}}/auth/login
Content-Type: application/json
```

```json
{
  "phone": "13800000000",
  "password": "casamind"
}
```

预期状态码为 `200`。将响应中的 `access_token` 写入 Yaak 环境变量 `access_token`。

### 7.2 查询成员列表

```http
GET {{base_url}}/members
Authorization: Bearer {{access_token}}
```

预期状态码为 `200`，已有本人画像的 `is_account_linked` 为 `true`。

### 7.3 新增成员画像

```http
POST {{base_url}}/members
Authorization: Bearer {{access_token}}
Content-Type: application/json
```

```json
{
  "name": "小满",
  "relationship": "女儿",
  "age_group": "儿童",
  "preferences": ["清淡", "喜欢鱼类"],
  "constraints": ["不吃辣", "花生过敏"],
  "availability": "工作日 19:00 后，周末全天",
  "notes": "只分配低风险、短时长的家庭任务",
  "avatar": "满",
  "color": "#5b8db8"
}
```

预期状态码为 `201`。把响应中的 `id` 写入 `member_id`。

### 7.4 查询单个成员

```http
GET {{base_url}}/members/{{member_id}}
Authorization: Bearer {{access_token}}
```

预期状态码为 `200`，且数据属于当前 JWT 指定的家庭空间。

### 7.5 局部修改成员

```http
PATCH {{base_url}}/members/{{member_id}}
Authorization: Bearer {{access_token}}
Content-Type: application/json
```

```json
{
  "constraints": ["不吃辣", "花生过敏", "晚餐不超过 30 分钟"],
  "availability": "周一至周五 19:00 后"
}
```

预期状态码为 `200`，未提交的字段保持不变。

### 7.6 验证 Graph RAG 使用新画像

```http
POST {{base_url}}/knowledge/search
Authorization: Bearer {{access_token}}
Content-Type: application/json
```

```json
{
  "query": "小满晚餐有哪些忌口和时间限制？",
  "top_k": 4
}
```

预期响应：

- `diagnostics.neo4j` 为 `connected`。
- `graph_hits` 包含 `小满` 的 `HAS_CONSTRAINT` 或 `PREFERS` 关系。
- 新增或修改画像后不需要手工执行 Neo4j 导入，下次检索或规划会重新同步当前家庭画像。

也可以调用 `POST {{base_url}}/plans/generate-weekly`，在响应的 `trace` 中检查 `Graph Retriever` 是否召回新成员约束。

### 7.7 删除普通画像

```http
DELETE {{base_url}}/members/{{member_id}}
Authorization: Bearer {{access_token}}
```

预期状态码为 `204`。再次查询该 ID 应返回 `404`。

### 7.8 验证关联账号删除保护

从成员列表取 `is_account_linked=true` 的成员 ID，调用删除接口。预期返回：

```text
409 Conflict
```

关联账号的成员画像必须保留，但允许通过 `PATCH` 修改偏好和约束。

## 8. 权限与家庭隔离验证

- 不携带 Token 调用 `/members`，预期 `401`。
- `member` 角色可以执行 `GET`，不能执行 `POST/PATCH/DELETE`，写操作预期 `403`。
- 切换到另一个家庭后，用新 Token 查询原家庭的 `member_id`，预期 `404`，而不是泄露原家庭成员。
- 请求体不接受 `family_id`。后端只使用 JWT 中经过数据库验证的家庭 ID。

### 11.1 创建一次性日程

先登录并将 `access_token` 写入 Yaak 环境变量，再调用 `GET {{base_url}}/members`，把任一成员画像 `id` 写入 `member_id`。

```http
POST {{base_url}}/calendar/events
Authorization: Bearer {{access_token}}
Content-Type: application/json
```

```json
{
  "title": "Piano class pickup",
  "start_at": "2026-08-04T19:00:00+08:00",
  "end_at": "2026-08-04T20:00:00+08:00",
  "participant_ids": ["{{member_id}}"],
  "category": "course",
  "location": "Community center",
  "notes": "Bring lesson book",
  "timezone": "Asia/Shanghai",
  "recurrence": {
    "type": "none",
    "interval": 1,
    "days_of_week": [],
    "until": null,
    "count": null
  },
  "is_all_day": false
}
```

预期 `201`。将响应中的 `id` 写入 `event_id`。

### 11.2 查询日程列表

```http
GET {{base_url}}/calendar/events?start_at=2026-08-04T00:00:00%2B08:00&end_at=2026-08-11T00:00:00%2B08:00
Authorization: Bearer {{access_token}}
```

预期 `200`，响应包含 `event_id`、`participant_ids`、`participants`、`recurrence` 和 occurrence 时间。

### 11.3 冲突预检

```http
POST {{base_url}}/calendar/conflicts/check
Authorization: Bearer {{access_token}}
Content-Type: application/json
```

```json
{
  "start_at": "2026-08-04T19:30:00+08:00",
  "end_at": "2026-08-04T20:30:00+08:00",
  "participant_ids": ["{{member_id}}"],
  "recurrence": {
    "type": "none",
    "interval": 1,
    "days_of_week": [],
    "until": null,
    "count": null
  }
}
```

预期 `200`，`has_conflict=true`，且 `conflicts[0].event_id` 等于 `event_id`。
