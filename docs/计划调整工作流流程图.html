SoloChef · 计划调整工作流

从自然语言修改要求 → LLM 解析 → 确定性重算 → 预览 → 确认派生新版本（完整生命周期）
① 用户输入自然语言修改要求
POST /plans/{plan_id}/revise
▼
② _parse_operation：LLM 解析为 ReviseOperation（8类）
无 LLM 时正则兜底 _parse_demo_operation
▼
③ 取 before 快照 _snapshot(plan, recipes)
记录修改前 meals / shopping / budget 状态
▼
④ PlanRevisionWorkflow：revision_intent 路由
operation → route + 所需智能体能力
▼
⑤ 条件边选中分支
MEAL / SHOPPING / BUDGET / CONSTRAINT / COMPOUND
▼
⑥ _apply_operation 确定性内存重算
replace / add / remove / exclude / budget / skip / macro / shopping
▼
⑦ affected_agents + dependency_sync
审计能力列表 + 置位（近乎空操作）
▼
⑧ 取 after 快照 _snapshot_from(...)
重算后的新状态
▼
⑨ 计算 delta + 冲突预警
nutrition / budget delta · 超预算 / 餐数≠21
▼
⑩ can_confirm = before ≠ after
是否有实际变更
▼
⑪ 持久化 ChatMessage.payload
存 before/after/operation/routing/modified_* → 返回 revise_id
▼
⑫ 前端展示 before/after diff 预览
用户确认 / 取消
▼
⑬ confirm：读 payload → derive_plan_with_modifications
派生新版本 parent_plan_id，无重复 LLM
▼
⑭ 新计划版本落库，旧版保留
completed
