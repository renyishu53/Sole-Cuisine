# 蒜苔炒肉

## 食材
- 蒜苔 150g
- 猪里脊肉 100g
- 蒜 2瓣
- 生抽 1勺、盐 少许

## 步骤
1. 蒜苔切段，里脊切丝，蒜切片。
2. 热锅少油，下肉丝快速滑炒至变色盛出。
3. 补少许油，爆香蒜片，下蒜苔大火翻炒2分钟。
4. 倒回肉丝，加生抽和盐，翻炒均匀即可出锅。

## 营养要点
- 优质蛋白来自瘦肉，约20g，饱腹感强。
- 总热量约220千卡，低脂高纤维。
- 适合减脂期或控糖人群，搭配杂粮饭更均衡。

## 独居适配
- 全程约10分钟，下班后快速搞定一餐。
- 蒜苔和肉丝可提前一晚切好冷藏，次日直接炒。
- 一次做一份，避免剩菜；多买的肉可切丝分装冷冻。
