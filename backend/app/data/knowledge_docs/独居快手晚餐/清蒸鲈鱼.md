# 清蒸鲈鱼

## 食材
鲈鱼 1条（约300g）、姜 3片、葱 2根、蒸鱼豉油 2勺、食用油 1勺

## 步骤
1. 鲈鱼洗净，两面各划两刀，姜片塞入鱼腹和刀口。
2. 水开后放入鱼盘，大火蒸8分钟，关火再焖2分钟。
3. 取出倒掉盘中腥水，铺上葱丝，淋上蒸鱼豉油。
4. 烧热食用油，均匀浇在葱丝和鱼身上即可。

## 营养要点
- 高蛋白低脂肪，每份约含25g优质蛋白，热量仅约180千卡。
- 富含DHA和EPA，有益心血管与脑健康，适合减脂增肌期。
- 无碳水和多余脂肪，饱腹感强，适合轻食晚餐。

## 独居适配
- 全程仅需15分钟，下班后现做现吃，无压力。
- 剩余鱼骨可留作次日煮汤，搭配豆腐或萝卜，一鱼两吃。
- 按300g小规格购买，一人食刚好，避免剩菜浪费。
