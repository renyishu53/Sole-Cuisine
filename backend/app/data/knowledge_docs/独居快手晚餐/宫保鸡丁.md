# 宫保鸡丁

## 食材
鸡胸肉 150g、花生米 30g、干辣椒 5-6个、葱白 2段

## 步骤
1. 鸡胸肉切丁，用1勺生抽、半勺淀粉抓匀腌5分钟。
2. 热锅少油，下干辣椒和葱白爆香，倒入鸡丁大火快炒至变色。
3. 加入2勺醋、1勺糖、半勺老抽调成的碗汁，翻炒收汁。
4. 关火拌入花生米，出锅即可。

## 营养要点
- 高蛋白低脂肪，鸡胸肉提供约30g优质蛋白。
- 热量约350-400千卡，适合减脂期或增肌期一餐。
- 花生富含不饱和脂肪酸，增加饱腹感。

## 独居适配
- 全程仅需10分钟，下班后快速开饭。
- 花生米可多炸些，剩余做凉拌菜或零食。
- 鸡丁一次可腌双份，另一半冷藏次日炒蔬菜用。
