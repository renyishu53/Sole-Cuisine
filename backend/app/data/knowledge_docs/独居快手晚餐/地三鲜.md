# 地三鲜

## 食材
土豆 1个（约150g）、茄子 1根（约150g）、青椒 1个、大蒜 3瓣、生抽 1勺

## 步骤
1. 土豆、茄子切滚刀块，青椒切块，蒜切末。
2. 热锅少油，先煎土豆至表面微黄，盛出备用。
3. 补少许油，下茄子煸软，加入土豆和青椒翻炒。
4. 加生抽和蒜末，翻炒均匀，焖1分钟即可出锅。

## 营养要点
- 植物蛋白与膳食纤维丰富，适合增肌或减脂期作为主食配菜。
- 总热量约250千卡，低脂低负担，适合控制热量摄入人群。
- 土豆提供优质碳水，饱腹感强，可替代部分主食。

## 独居适配
- 全程约15分钟，备菜简单，一锅完成，减少洗刷。
- 土豆、茄子可提前一晚切好冷藏，次日直接下锅。
- 一次做一份刚好，避免剩菜；剩余食材可搭配鸡蛋或肉片另做一餐。
