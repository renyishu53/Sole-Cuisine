# 番茄牛腩

## 食材
牛腩 200g、番茄 2 个、洋葱 1/4 个、姜 2 片、番茄酱 1 勺

## 步骤
1. 牛腩切块冷水下锅，煮沸撇沫后捞出沥干。
2. 番茄去皮切块，洋葱切丝，姜切片备用。
3. 锅中少油爆香姜和洋葱，下番茄炒出沙，加番茄酱炒匀。
4. 放入牛腩，加开水没过食材，小火炖 40 分钟。
5. 加盐调味，大火收汁至浓稠即可出锅。

## 营养要点
- 优质蛋白与胶原蛋白丰富，饱腹感强。
- 热量约 350-400 千卡/份，适合增肌或减脂期控制碳水的正餐。
- 番茄富含番茄红素和维C，搭配牛肉促进铁吸收。

## 独居适配
- 一次炖一锅，可分装冷藏，工作日热食 3 分钟搞定。
- 剩余汤汁可拌面或煮土豆，实现“一菜两吃”。
- 牛腩按 200g 分装冷冻，解冻即用，避免浪费。
