# 香菇滑鸡

## 食材
鸡腿肉 200g、干香菇 6朵、姜丝 10g、葱花 少许、生抽/淀粉/料酒 各1勺

## 步骤
1. 干香菇温水泡发15分钟，切片；鸡腿肉切小块，用料酒、生抽、淀粉抓匀腌10分钟。
2. 将香菇片、姜丝与鸡肉混合，淋少许泡香菇的水。
3. 放入微波炉，高火加热6分钟（或蒸锅大火蒸12分钟）。
4. 取出撒上葱花，拌匀即可。

## 营养要点
- 鸡腿肉提供优质蛋白和B族维生素，热量约280千卡/份，饱腹感强。
- 香菇富含多糖和膳食纤维，低脂低卡，适合减脂期或日常控卡饮食。
- 蛋白质含量约25g，适合增肌或上班族午餐便当。

## 独居适配
- 全程约20分钟，可提前一晚腌好鸡肉，次日直接加热。
- 干香菇与剩余鸡肉可做香菇鸡肉粥或炒饭，一材两吃。
- 份量按200g鸡肉正好一餐，避免剩菜浪费；用微波炉省去刷锅。
