# 蛋炒饭

## 食材
隔夜米饭 1碗（约200g）、鸡蛋 2 个、火腿丁 50g、葱花 少许、生抽 1勺

## 步骤
1. 鸡蛋打散，热锅冷油炒至半凝固盛出。
2. 锅中留底油，下米饭中火翻炒至粒粒松散。
3. 加入火腿丁和炒蛋，淋入生抽快速翻匀。
4. 撒葱花，再翻炒半分钟即可出锅。

## 营养要点
- 鸡蛋和火腿提供优质蛋白，饱腹感强。
- 总热量约 450-500 千卡，适合作为正餐。
- 碳水为主、脂肪适中，适合增肌或日常能量补充。

## 独居适配
- 全程约 8 分钟，下班后轻松搞定。
- 火腿可换剩菜、虾仁或蔬菜，一料多用不浪费。
- 米饭按一人份冷藏，一次煮好分装，随取随炒。
