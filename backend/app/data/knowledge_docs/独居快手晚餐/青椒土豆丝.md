# 青椒土豆丝

## 食材
土豆 1个（约200g）、青椒 1个、大蒜 2瓣、干辣椒 2个、食用油 15ml

## 步骤
1. 土豆去皮切细丝，放入清水中浸泡10分钟，捞出沥干。
2. 青椒去籽切丝，大蒜切片，干辣椒剪段。
3. 热锅倒油，爆香蒜片和干辣椒，倒入土豆丝大火快炒2分钟。
4. 加入青椒丝再炒1分钟，加盐和少许醋，翻炒均匀即可出锅。

## 营养要点
- 低碳水、低脂肪，一份约120千卡，适合减脂期作为主食替代。
- 富含维生素C和钾，土豆丝浸泡去淀粉后升糖指数降低。
- 搭配鸡蛋或鸡胸肉可补充蛋白质，营养更均衡。

## 独居适配
- 全程仅需10分钟，下班后快速解决一餐。
- 土豆和青椒可冷藏保存3天，剩余食材可做青椒炒蛋或烤土豆块。
- 一人份刚好一盘，避免剩菜浪费，控制份量轻松。
