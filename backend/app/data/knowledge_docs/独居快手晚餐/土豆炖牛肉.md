# 土豆炖牛肉

## 食材
牛腩 200g、土豆 1 个（约150g）、胡萝卜 半根、洋葱 1/4 个、生抽 2 勺

## 步骤
1. 牛腩切块冷水下锅，煮沸撇沫后捞出。
2. 土豆、胡萝卜切滚刀块，洋葱切丝。
3. 锅中少油炒香洋葱，下牛肉块翻炒2分钟。
4. 加生抽和足量热水，小火炖25分钟。
5. 加入土豆、胡萝卜再炖15分钟，大火收汁即可。

## 营养要点
- 优质蛋白与碳水结合，饱腹感强，适合增肌或减脂期午餐。
- 总热量约450-550千卡，脂肪含量可控，搭配蔬菜更均衡。
- 富含铁和维生素B12，有助于改善独居常见的疲劳状态。

## 独居适配
- 一次炖一锅，可分装冷藏，工作日加热即食，节省3天备餐时间。
- 剩余汤汁可拌面或煮青菜，一菜两吃不浪费。
- 牛腩可按100g/份分装冷冻，用时取一份，方便控制份量。
