# 麻婆豆腐

## 食材
嫩豆腐 300g、猪肉末 80g、蒜末 1勺、豆瓣酱 1勺、花椒粉 1/2勺

## 步骤
1. 豆腐切块，沸水加盐焯1分钟捞出。
2. 热锅少油，炒香肉末至变色，加蒜末、豆瓣酱炒出红油。
3. 倒入豆腐，加半碗水，轻推煮3分钟。
4. 淋入水淀粉勾芡，撒花椒粉即可出锅。

## 营养要点
- 豆腐提供优质植物蛋白，肉末补充动物蛋白，蛋白质总量约25g。
- 整份热量约280-320千卡，适合减脂期作为主菜。
- 豆瓣酱含钠较高，血压敏感者需减少用量。

## 独居适配
- 全程约15分钟，下班后快速出餐。
- 剩余豆腐可切块冷冻，下次做汤或煎制不浪费。
- 一盒豆腐分两半，一半做麻婆豆腐，一半做凉拌，解决两餐。
