# 红烧茄子

## 食材
紫茄子 1根（约300g）、大蒜 3瓣、生抽 2勺、蚝油 1勺、白糖 半勺

## 步骤
1. 茄子洗净切滚刀块，撒盐腌10分钟，挤干水分备用。
2. 热锅少油，下茄子中火煸炒至表面微黄变软。
3. 加入蒜末爆香，倒入生抽、蚝油、白糖和半碗清水。
4. 翻匀后盖锅盖焖3分钟，开盖收汁至浓稠即可出锅。

## 营养要点
- 茄子富含膳食纤维，搭配蒜末有助于提升代谢。
- 整道菜热量约150-180千卡，低油低脂，适合减脂期。
- 植物性食材为主，可作为素食主菜或搭配杂粮饭。

## 独居适配
- 备餐仅需15分钟，腌茄子时同步煮饭，效率高。
- 茄子易吸油，用盐杀水可减少用油量，控制成本。
- 一次做一盘可分两顿吃，第二顿加热风味不减。
