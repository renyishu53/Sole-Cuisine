# 菠菜拌粉丝

## 食材
菠菜 200g、龙口粉丝 1把（约50g）、蒜末 2瓣、生抽 1勺、香醋 1勺、香油 半勺、白芝麻 少许

## 步骤
1. 粉丝用温水泡软（约10分钟），菠菜洗净切段。
2. 锅中烧水，水开先下粉丝煮1分钟捞出，再下菠菜焯烫30秒，立即过凉水。
3. 将菠菜攥干水分，与粉丝一同放入碗中，加入蒜末、生抽、香醋、香油拌匀。
4. 撒上白芝麻即可装盘，冷藏后风味更佳。

## 营养要点
- 菠菜富含铁和叶酸，粉丝提供碳水，整体低脂高纤。
- 热量约150-180千卡，适合减脂期或轻食晚餐。
- 搭配少量鸡胸肉或豆腐可增加优质蛋白。

## 独居适配
- 全程约15分钟，一锅水完成焯烫和煮粉，省时省力。
- 菠菜、粉丝可提前分装冷藏，次日快手复拌或煮汤，避免浪费。
- 单人份量易控制，剩料可做菠菜鸡蛋汤，实现一材两吃。
