# 韭菜炒鸡蛋

## 食材
韭菜 150g、鸡蛋 2 个、盐 2g、食用油 10ml

## 步骤
1. 韭菜洗净切 3cm 段，鸡蛋加少许盐打散。
2. 热锅倒油，倒入蛋液炒至凝固，盛出备用。
3. 锅内补少许油，下韭菜大火翻炒 30 秒。
4. 倒回鸡蛋，加盐快速翻炒均匀，出锅。

## 营养要点
- 鸡蛋提供优质蛋白，韭菜富含膳食纤维和维生素 A。
- 总热量约 200 千卡，适合减脂或轻食晚餐。
- 低升糖、饱腹感强，适合控糖或增肌人群。

## 独居适配
- 全程 5 分钟，适合下班后快速开火。
- 韭菜可一次买半把，剩余切段冷冻，炒蛋或煮面随取随用。
- 单人份用 2 个蛋、一把菜，无剩菜烦恼。
