# 香煎鸡胸配糙米

## 食材
鸡胸肉 180g、糙米 80g、西兰花 100g、橄榄油半勺、黑胡椒与盐少许

## 步骤
1. 糙米提前浸泡后煮熟。
2. 鸡胸肉两面撒盐和黑胡椒，平底锅少油煎至两面金黄，静置 3 分钟切片。
3. 西兰花焯水，与鸡胸、糙米一同摆盘。

## 营养要点
- 鸡胸提供约 42g 优质蛋白，糙米缓释碳水，适合增肌期午餐。
- 总热量约 520 千卡，蛋白质供能占比高，饱腹持久。

## 独居适配
- 鸡胸可一次煎两餐份，冷藏复热，减少工作日烹饪次数。
- 糙米按餐分装冷冻，避免整锅反复加热流失口感。
